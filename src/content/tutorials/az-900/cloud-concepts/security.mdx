## Start with a question

<Story question="Who protects your company's servers better, one IT person with a key to the server cupboard, or thousands of security specialists, guards, cameras and biometric scanners?">

Many small and medium businesses keep servers in an office cupboard. The "security" is a door lock and a hope that nobody spills coffee.

Microsoft's datacenters have perimeter fences, security staff, multi-factor physical access, and teams monitoring for attacks around the clock. **Moving to the cloud gives you all of that on day one**, as long as you secure your own part.

</Story>

## Explain it like I'm 10

<Eli10>

Imagine keeping your savings in a **piggy bank** at home versus in a **real bank**. The bank has thick vault doors, alarms, cameras and guards. Your piggy bank has… a cork.

The cloud is like the bank: much better protection than you could build yourself. But you still have to **keep your PIN secret**, because the bank can't protect you if you give it away.

</Eli10>

## The technical explanation

Microsoft's AZ-900 material frames the security benefit like this: **whether you want maximum control or want the provider to handle most of it, the cloud supports your needs.**

- Want **maximum control** of security configuration? Use **IaaS**. You manage the OS, patches and installed software.
- Want **patches and maintenance handled for you**? Use **PaaS or SaaS**. Microsoft patches the platform automatically.
- In every case, the provider handles **physical security** and offers built-in **network protection**, including defence against **DDoS attacks**.

### Built-in security you get from Azure

| Protection | What Azure provides |
| --- | --- |
| Physical security | Restricted, monitored datacenters run by Microsoft |
| Encryption | Encryption at rest on by default for Azure Storage and Azure SQL Database; TLS in transit |
| DDoS | Infrastructure-level protection for all; Azure DDoS Protection for enhanced, tuned protection |
| Patching | Automatic for PaaS and SaaS platforms |
| Posture and threats | Microsoft Defender for Cloud: secure score, recommendations, threat detection |
| Secrets | Azure Key Vault for keys, secrets and certificates |

<Callout type="warning">
The cloud provides strong security **tools**, but they only help if you use them. The most common cloud incidents are **stolen credentials without MFA** and **resources accidentally exposed to the internet**. Both are customer-side configuration issues.
</Callout>
