## The technical explanation

| Capability | What it does |
| --- | --- |
| Cost analysis | Explore spend by service, resource group, tag, location and time |
| Budgets | Spending thresholds on subscriptions, resource groups or management groups |
| Alerts | Budget, credit, department quota and anomaly alerts |
| Recommendations | Right-sizing, reservations and shutting down idle resources (from Azure Advisor) |
| Exports | Scheduled cost data exports for reporting |
