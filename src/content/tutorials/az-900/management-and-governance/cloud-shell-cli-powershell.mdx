## Start with a question

</Story>

## Explain it like I'm 10

<Eli10>

Clicking in the portal is like drawing a picture by hand. Typing commands is like giving a **robot instructions**: write them once, and the robot draws the same picture perfectly every time.

</Eli10>

## The technical explanation

The same task in both tools:

```bash
# Azure CLI
az group create --name rg-learn --location westeurope
```

```powershell
# Azure PowerShell
New-AzResourceGroup -Name rg-learn -Location westeurope
```
