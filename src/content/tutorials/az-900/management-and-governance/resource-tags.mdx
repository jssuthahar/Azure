## Start with a question

</Story>

## Explain it like I'm 10

<Eli10>

Tags are **name stickers** on your school things: "Owner: Sam", "Class: 5B". When things get mixed up, you can sort them by sticker.

</Eli10>

## The technical explanation

Each resource can have many tags. Typical tags:

| Name | Example value | Used for |
| --- | --- | --- |
| env | production, dev | Automation, policy |
| owner | `sam@contoso.com` | Accountability |
| costCenter | 1234 | Cost reporting |
| dataClass | confidential | Security |
