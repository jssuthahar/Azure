## Start with a question

<Story question="Where in your company is every copy of a customer’s personal data?">

## Explain it like I'm 10

<Eli10>

Purview is like a **librarian for all your data**. It walks around every shelf (database, file share, cloud app), writes a catalogue of every book, puts "secret" stickers on private ones, and remembers where each book was copied from.

</Eli10>

## The technical explanation

| Area | Capabilities |
| --- | --- |
| Unified data governance | Data map, catalogue, automated scanning and classification, lineage |
| Risk and compliance | Information protection, sensitivity labels, data loss prevention, compliance management |
| Sources | Azure, on-premises SQL and file shares, other clouds, SaaS such as Microsoft 365 |
