## Explain it like I'm 10

<Eli10>

The Azure portal is like the **control panel of a video game**: buttons and menus to build things, see how they're doing and change settings, without typing any code.

</Eli10>

## The technical explanation

The portal provides a graphical way to create resources (through wizards like "Create a resource"), browse resource groups, configure settings, view metrics and logs, manage access, check costs and launch Cloud Shell. Every action goes through **Azure Resource Manager**, the same as the CLI and PowerShell.
