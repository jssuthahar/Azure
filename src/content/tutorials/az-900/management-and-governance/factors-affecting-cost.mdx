## Start with a question

<Story question="Two teams run the same app on Azure. Why does one pay twice as much?">

Different region, bigger sizes, data flowing out of Azure, and forgotten resources. Every one of these is a **cost factor**.

</Story>

## Explain it like I'm 10

<Eli10>

Your phone bill depends on your **plan**, how many **minutes** you use, whether you call **abroad**, how much **data** you download, and whether you forgot to cancel that **extra subscription**. Azure bills work the same way.

</Eli10>

## The technical explanation

| Factor | Example |
| --- | --- |
| Resource type | VM size, storage tier and redundancy, database tier |
| Consumption | Hours a VM runs, GB stored, number of executions |
| Maintenance | Deleting unused VMs, disks, IPs, old snapshots |
| Geography | The same service costs different amounts in different regions |
| Network traffic | Outbound data transfer and inter-region traffic |
| Subscription type | Free trials, student credits, enterprise agreements |
| Azure Marketplace | Third-party solutions billed through Azure |
