## Start with a question

<Story question="Your test environment works perfectly, but production behaves differently. Why?">

Because they were built by hand, at different times, by different people. **Infrastructure as code** builds them from the same recipe.

</Story>

## Explain it like I'm 10

<Eli10>

IaC is like **LEGO instructions**. Anyone with the same instructions builds the exact same model every time, and if it breaks, you rebuild it in minutes.

</Eli10>

## The technical explanation

A small **Bicep** file describing a storage account:

```bicep
resource st 'Microsoft.Storage/storageAccounts@2023-05-01' = {
  name: 'stlearn0412'
  location: 'westeurope'
  sku: { name: 'Standard_ZRS' }
  kind: 'StorageV2'
}
```

Deploy it with `az deployment group create --resource-group rg-learn --template-file main.bicep`. Run it again and nothing changes, because it is already in the desired state (**idempotent**).
