answer: >-
  **Azure Resource Manager (ARM)** is the deployment and management service for Azure. Every request, from the portal, CLI, PowerShell, SDKs or templates, goes through ARM, which authenticates and authorises it and then creates, updates or deletes resources. **ARM templates** are declarative **JSON** files that describe the resources to deploy. Bicep is a simpler language that compiles to ARM templates.

## Start with a question

<Story question="You click Create in the portal and a teammate runs az vm create. Who actually builds the VM?">

**Azure Resource Manager** builds both. Every tool talks to the same front door.

</Story>

## Explain it like I'm 10

<Eli10>

ARM is the **head chef** in a restaurant. Whether you order from the waiter (portal), the app (CLI) or a written note (template), every order goes to the same chef, who checks it and cooks it the same way.

</Eli10>
