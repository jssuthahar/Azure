## Explain it like I'm 10

<Eli10>

Advisor is like a **coach** watching your football team. "Your goalkeeper needs gloves" (security), "you're running too much" (cost), "practise passing" (performance). Helpful tips based on how *your* team actually plays.

</Eli10>

## The technical explanation

| Category | Example recommendation |
| --- | --- |
| Reliability | Use availability zones; enable VM backup |
| Security | Enable MFA; fix vulnerabilities (from Defender for Cloud) |
| Performance | Upgrade a storage tier with throttling |
| Operational Excellence | Create Service Health alerts; follow naming and tagging |
| Cost | Resize or shut down underused VMs; buy reservations |
