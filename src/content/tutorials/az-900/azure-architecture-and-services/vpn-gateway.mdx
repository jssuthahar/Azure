## Start with a question

<Story question="How does your office talk to Azure privately if the only road between them is the public internet?">

You build a **tunnel**: an encrypted VPN connection that wraps your data so nobody on the internet can read it.

</Story>

## Explain it like I'm 10

<Eli10>

Imagine sending a letter in a **locked metal box** through the normal post. The postman carries it on public roads, but only you and your friend have the key. That locked box is a VPN.

</Eli10>

## The technical explanation

A **VPN gateway** is deployed into a dedicated **GatewaySubnet** in your VNet and uses IPsec/IKE encryption.

| Type | Connects | Typical use |
| --- | --- | --- |
| Site-to-site | On-premises network ↔ Azure | Branch or head office |
| Point-to-site | Individual device ↔ Azure | Remote workers, admins |
| VNet-to-VNet | Azure VNet ↔ Azure VNet | Encrypted link between VNets |
