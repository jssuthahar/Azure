## Explain it like I'm 10

</Eli10>

## The technical explanation

A **VNet** is defined by a private **address space** and divided into **subnets**. Resources in the same VNet can communicate by default; you control everything else.

| Capability | How |
| --- | --- |
| Isolation and segmentation | Separate VNets and subnets |
| Internet communication | Public IPs, load balancers, NAT |
| Communicate between Azure resources | Same VNet, or peering, or service endpoints |
| Communicate with on-premises | VPN Gateway or ExpressRoute |
| Route traffic | System routes, route tables (UDRs) |
| Filter traffic | Network security groups, Azure Firewall |
