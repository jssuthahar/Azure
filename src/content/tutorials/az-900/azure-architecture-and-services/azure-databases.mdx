## Explain it like I'm 10

<Eli10>

- **SQL on a VM**: you build and look after your own bookshelf.
- **Managed Instance**: a library copies your exact bookshelf and looks after it.
- **SQL Database**: the library gives you a modern shelf and does everything.
- **Cosmos DB**: magic shelves in every city, so books appear instantly wherever you are.

</Eli10>

## The technical explanation

| Option | Type | Best for |
| --- | --- | --- |
| SQL Server on Azure VMs | IaaS | Full control, specific versions, OS access |
| Azure SQL Managed Instance | PaaS | Migrating existing SQL Server with minimal changes |
| Azure SQL Database | PaaS | New cloud apps, serverless and Hyperscale options |
| Azure Cosmos DB | PaaS NoSQL | Global apps needing low latency and flexible schema |
