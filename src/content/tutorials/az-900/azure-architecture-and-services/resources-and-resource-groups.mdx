## The technical explanation

A **resource** is a manageable item in Azure: virtual machines, storage accounts, web apps, databases, virtual networks and so on. Every resource lives in a **resource group**, a logical container managed through Azure Resource Manager.

| Rule | What it means |
| --- | --- |
| One group per resource | A resource belongs to exactly one resource group (it can be moved) |
| No nesting | You can't put a resource group inside another |
| Mixed regions | Resources can be in different regions from the group |
| Delete together | Deleting a group deletes everything in it |
| Inheritance | RBAC permissions and Azure Policy on a group apply to its resources |
