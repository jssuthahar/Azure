## Start with a question

<Story question="If the castle has only one wall, what happens when it falls?">

The castle falls. Real castles had moats, walls, towers and guards. **Defense in depth** builds security the same way.

</Story>

## Explain it like I'm 10

<Eli10>

Your treasure is in a **box**, inside a **locked drawer**, inside a **locked room**, inside a **house with an alarm**. A thief would need to beat all of them.

</Eli10>

## The technical explanation

| Layer | Purpose | Azure examples |
| --- | --- | --- |
| Physical | Protect buildings and hardware | Microsoft datacenter security |
| Identity and access | Control who gets in | Entra ID, MFA, Conditional Access |
| Perimeter | Stop network attacks at the edge | DDoS Protection, Azure Firewall |
| Network | Limit communication | NSGs, segmentation, private endpoints |
| Compute | Secure VMs and containers | Patching, Defender for Servers, Bastion |
| Application | Build secure apps | Secure code, WAF, Key Vault |
| Data | Protect the information itself | Encryption, access controls, Purview |
