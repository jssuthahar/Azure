## Start with a question

<Story question="Where does an app keep millions of photos, shared folders and messages in the cloud?">

In an **Azure storage account**: one uniquely named home for several kinds of storage.

</Story>

## Explain it like I'm 10

<Eli10>

A storage account is like your own **locker room** with one name on the door. Inside are different lockers: one for pictures (blobs), one for shared folders (files), one for notes to pass around (queues) and one for lists (tables).

</Eli10>

## The technical explanation

| Account type | Supports | Redundancy |
| --- | --- | --- |
| Standard general-purpose v2 | Blobs (incl. Data Lake Storage), files, queues, tables | LRS, GRS, RA-GRS, ZRS, GZRS, RA-GZRS |
| Premium block blobs | Block and append blobs | LRS, ZRS |
| Premium file shares | Azure Files | LRS, ZRS |
| Premium page blobs | Page blobs | LRS |

Each service gets its own **endpoint**: `https://<name>.blob.core.windows.net`, `.file.`, `.queue.` and `.table.core.windows.net`.
