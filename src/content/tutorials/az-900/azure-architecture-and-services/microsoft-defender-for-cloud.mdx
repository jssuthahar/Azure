## Start with a question

<Story question="You have 300 cloud resources. Which ones have a security hole right now?">

You'd never find them by hand. **Defender for Cloud** checks them continuously and tells you.

</Story>

## Explain it like I'm 10

<Eli10>

Defender for Cloud is like a **health check-up** for your computers. It gives a score, tells you what to fix ("brush your teeth, close that open door!"), and raises the alarm if a germ (attacker) gets in.

</Eli10>

## The technical explanation

- **Posture management:** continuous assessment, **secure score**, recommendations, regulatory compliance dashboard.
- **Workload protection:** Defender plans for servers, containers, storage, databases, App Service, Key Vault and more, with threat alerts.
- **Coverage:** Azure, hybrid via **Azure Arc**, and **multi-cloud** via AWS and GCP connectors.
