  - term: Trigger

    q: What are triggers and bindings?
    a: >-
      A trigger is what starts the function, and every function has exactly one. Bindings are optional input and output connections to other services, like reading a blob or writing to a queue, declared in configuration instead of written in code.

## Start with a question

<Story question="Why keep a server running all day to resize five photos an hour?">

You don't have to. **Azure Functions** wakes up when a photo arrives, resizes it, and goes back to sleep.

</Story>

## Explain it like I'm 10

<Eli10>

A function is like a **doorbell**. Nothing happens until someone presses it, then it rings once and stops. You don't pay for a doorbell sitting quietly on the wall.

</Eli10>
