## Start with a question

<Story question="Should the new intern be able to delete the production database?">

Certainly not. **Azure RBAC** makes sure each person gets just the access they need.

</Story>

## Explain it like I'm 10

<Eli10>

At school, the **caretaker** has keys to every room, **teachers** have keys to their classrooms, and **students** can only look through the window. Each person gets the right keys for their job. That's RBAC.

</Eli10>

## The technical explanation

| Built-in role | Can do |
| --- | --- |
| Owner | Everything, including granting access to others |
| Contributor | Create and manage resources, but not grant access |
| Reader | View resources only |
| User Access Administrator | Manage user access only |

Role assignments at a scope are **inherited** by all child scopes. RBAC uses an **allow** model: permissions add up across assignments.
