  All three spread traffic across servers, at different layers. **Azure Load Balancer** works at layer 4 (TCP/UDP) within a region. **Application Gateway** is a regional layer-7 web load balancer with URL-based routing, TLS termination and an optional Web Application Firewall. **Azure Front Door** is a global layer-7 entry point that routes users to the nearest healthy region, with caching and WAF.

keyTerms:
  - term: Layer 4
    definition: Transport layer (TCP/UDP). Routing by IP address and port only.
  - term: Layer 7
    definition: Application layer (HTTP/HTTPS). Routing can use URLs, headers and cookies.
  - term: Web Application Firewall (WAF)
    definition: Protects web apps from common attacks such as SQL injection and cross-site scripting.
  - term: Health probe
    definition: A regular check that removes unhealthy backends from rotation.
interview:
  - level: beginner
    q: What does a load balancer do?
    a: >-
      It spreads incoming traffic across several servers and stops sending traffic to any server that fails a health check, so the app stays fast and available.
    followUps: []
  - level: intermediate
    q: How do you choose between Load Balancer, Application Gateway and Front Door?
    a: >-
      Load Balancer for non-HTTP or high-performance layer-4 traffic in one region. Application Gateway for web apps in one region needing URL routing, TLS offload or WAF. Front Door for global web apps that need users routed to the closest healthy region, with caching and WAF at the edge.
    followUps: []
  - level: experienced
    q: Would you ever combine them?
    a: >-
      Yes. A common pattern is Front Door globally, routing to Application Gateway or directly to App Service in each region, with internal Load Balancers in front of VM-based back-end tiers. Front Door handles global failover; regional services handle local distribution.
    followUps: []

## Start with a question

<Story question="Your shop has customers in Europe and Asia and ten servers. Who decides which server answers each customer?">

A **load balancer**. Azure has several, each for a different kind of job.

</Story>

## Explain it like I'm 10

<Eli10>

- **Load Balancer** is a lollipop lady sending children to any open classroom door.
- **Application Gateway** reads the child's note: "art class" goes to the art room, "maths" to the maths room.
- **Front Door** works for schools in many cities and sends each child to the nearest open school.

</Eli10>
