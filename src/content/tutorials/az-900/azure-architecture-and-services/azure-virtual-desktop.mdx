It's like watching a cartoon on a **streaming app**: the cartoon isn't stored on your tablet, it streams from far away. Azure Virtual Desktop streams a whole computer screen to you.

</Eli10>

## The technical explanation

Azure Virtual Desktop runs **session host VMs** in Azure and streams desktops or individual apps to users through the Remote Desktop client or a browser. Key features:

- **Windows multi-session** (Windows 10/11 Enterprise multi-session) for multiple users per VM.
- Identity with **Microsoft Entra ID**, plus **MFA** and **Conditional Access**.
- Data stays in Azure; the user's device only receives pixels.
- Autoscaling host pools to save money outside working hours.
