## The technical explanation

Microsoft Entra ID provides:

- **Authentication**: verifying identity, password reset, MFA, smart lockout.
- **Single sign-on**: one identity for many apps.
- **Application management**: register and manage access to cloud and on-premises apps.
- **Device management**: register devices and use them in access policies.

**Microsoft Entra Connect** synchronises users from on-premises Active Directory. **Microsoft Entra Domain Services** adds managed **domain join, Group Policy, LDAP and Kerberos/NTLM** for legacy workloads, with Microsoft running the domain controllers.
