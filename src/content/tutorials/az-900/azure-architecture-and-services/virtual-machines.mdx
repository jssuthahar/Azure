## Start with a question

<Story question="How do you get a new server running in minutes, without buying one?">

You create an **Azure virtual machine**: pick an operating system, pick a size, click create.

</Story>

## Explain it like I'm 10

<Eli10>

Imagine a giant computer that can split itself into many smaller pretend computers. Each pretend computer has its own screen, files and programs. Azure lends you one of those pretend computers. That is a **virtual machine**.

</Eli10>

## The technical explanation

When you create a VM, you choose:

| Choice | Examples |
| --- | --- |
| Image (operating system) | Ubuntu Server, Windows Server, Red Hat |
| Size | Standard_B1s (1 vCPU, 1 GiB) up to very large memory and GPU sizes |
| Region and availability | A region, and optionally an availability zone or availability set |
| Networking | Virtual network, subnet, public IP, inbound ports |

<Callout type="warning">
Shutting down the operating system leaves the VM <strong>allocated</strong> and still billed for compute. Use <strong>Stop</strong> in the portal (deallocate) to stop compute charges.
