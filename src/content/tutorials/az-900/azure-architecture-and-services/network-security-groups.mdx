  A **network security group (NSG)** is a basic firewall for Azure virtual networks. It contains **security rules** that allow or deny inbound and outbound traffic based on source, destination, port and protocol. You attach an NSG to a **subnet** or a **network interface**, and rules are evaluated in **priority** order.

  - term: NSG

  - term: Security rule
    definition: A rule with priority, source, destination, port, protocol and action (allow or deny).
  - term: Priority
    definition: A number from 100 to 4096; lower numbers are processed first.
interview:
  - level: beginner
    q: What is a network security group?
    a: >-
      It's a list of firewall rules for Azure networks. Each rule allows or blocks traffic based on where it comes from, where it goes, the port and the protocol.
    followUps: []
  - level: intermediate
    q: How are NSG rules evaluated?
    a: >-
      By priority. The lowest number is checked first, and processing stops at the first rule that matches. Default rules allow traffic within the VNet and from the Azure load balancer, and deny other inbound traffic from the internet.
    followUps: []
  - level: experienced
    q: NSG or Azure Firewall?
    a: >-
      NSGs are free, distributed, layer 3 and 4 filters on subnets and NICs, ideal for segmentation. Azure Firewall is a managed, stateful, centralised firewall with FQDN filtering, threat intelligence and logging, used in a hub to control traffic between networks and the internet. Most designs use both.

## Start with a question

<Story question="Who decides which visitors can knock on your server’s door?">

A **network security group**: a list of rules saying who may come in, on which door (port), and who must be turned away.

</Story>

## Explain it like I'm 10

<Eli10>

An NSG is like the **guest list at a party**. The bouncer checks each visitor against the list from top to bottom. "Friends from school: allowed. Strangers: not allowed." The first matching rule wins.

</Eli10>

## The technical explanation

| Priority | Name | Port | Source | Action |
| --- | --- | --- | --- | --- |
| 100 | Allow-HTTPS | 443 | Internet | Allow |
| 200 | Allow-SSH-from-office | 22 | 203.0.113.0/24 | Allow |
| 65500 | DenyAllInBound (default) | Any | Any | Deny |
