## Start with a question

<Story question="Your database is in the cloud. Should anyone on the internet be able to knock on its door?">

Ideally not. A **private endpoint** moves the door inside your private network.

</Story>

## Explain it like I'm 10

<Eli10>

A **public endpoint** is a shop door on the main street: anyone can walk up. A **private endpoint** is a door that opens only from inside your house, through your own hallway.

</Eli10>

## The technical explanation

PaaS services (Storage, SQL Database, Key Vault and many more) have **public endpoints** by default. A **private endpoint** creates a network interface in your subnet with a private IP, mapped to one specific resource through **Azure Private Link**. Combine it with **private DNS zones** and **disable public network access** for strong isolation.
