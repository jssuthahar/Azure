</Story>

## Explain it like I'm 10

<Eli10>

Your phone stores friends by **name**, but it actually dials a **number**. DNS is the contacts app of the internet: you type a name, it finds the number.

</Eli10>

## The technical explanation

Azure DNS hosts **DNS zones** containing records such as A (IPv4), AAAA (IPv6), CNAME (alias name), MX (mail) and TXT. It uses a global network of name servers with **anycast** routing for fast, reliable answers. **Private DNS zones** provide name resolution inside VNets, and **alias records** point straight at Azure resources such as public IPs or Front Door.
