## The technical explanation

**Azure App Service** hosts **web apps**, **API apps** and **mobile back ends** on Windows or Linux. You deploy code or containers through Git, GitHub Actions, Azure DevOps, ZIP or FTP.

| Feature | Why it helps |
| --- | --- |
| Autoscale | More instances when traffic rises |
| Deployment slots | Zero-downtime releases with swap and rollback |
| Custom domains and HTTPS | Professional, secure sites |
| Built-in authentication | Sign-in with Microsoft Entra ID and others |
| VNet integration and private endpoints | Private connectivity to databases and services |
