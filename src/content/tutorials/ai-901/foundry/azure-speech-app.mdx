## Start with a question

<Story question="How does a railway announcement app know how to say 'platform 4' in a calm, clear voice?">

Station announcements used to be recorded by a person, one clip per train. Change the platform and someone had to record it again.

Today an app can take the text "The 6:40 Chennai Express will arrive on platform 4" and speak it in a natural voice, in English or Hindi, slower for the platform number. And it can do the reverse too, turning a passenger's spoken question into text. That's **Azure Speech**.

</Story>

## Explain it like I'm 10

<Eli10>

Azure Speech is two magic tricks in one box.

Trick one: it listens and writes down what you said, like a super-fast typist (**speech to text**).

Trick two: it reads any sentence out loud in a friendly voice (**text to speech**). You can even tell it "slow down here" or "take a breath there", and it does.

</Eli10>

## The technical explanation

**Azure Speech in Foundry Tools** is available on your Foundry resource (or a standalone Speech resource). Your app needs the key and endpoint, which you'll find on the resource in the Azure portal or Foundry portal.

| Feature | What it does | SDK piece |
| --- | --- | --- |
| Speech to text (real time) | Transcribes a file or live microphone | `SpeechRecognizer` |
| Fast and batch transcription | Transcribes long or many recordings | REST APIs |
| Text to speech | Speaks text with a neural voice | `SpeechSynthesizer` |
| SSML | Controls voice, rate, pitch, pauses, style | `speak_ssml_async` |
| Speech translation | Spoken input to translated text or speech | `TranslationRecognizer` |
| Speaker diarization | Labels who spoke when | Transcription options |

```bash
pip install azure-cognitiveservices-speech
export SPEECH_KEY="<key>"
export ENDPOINT="https://<resource-name>.cognitiveservices.azure.com/"
```

### speech_app.py: speech to text

```python
import os
import azure.cognitiveservices.speech as speechsdk

speech_config = speechsdk.SpeechConfig(subscription=os.environ["SPEECH_KEY"], endpoint=os.environ["ENDPOINT"])
speech_config.speech_recognition_language = "en-IN"

# From a file. Use AudioConfig(use_default_microphone=True) for the mic.
audio_config = speechsdk.audio.AudioConfig(filename="question.wav")
recognizer = speechsdk.SpeechRecognizer(speech_config=speech_config, audio_config=audio_config)

result = recognizer.recognize_once_async().get()  # one utterance, up to about 30 seconds
if result.reason == speechsdk.ResultReason.RecognizedSpeech:
    print("You said:", result.text)
elif result.reason == speechsdk.ResultReason.NoMatch:
    print("No speech could be recognised.")
```

`recognize_once` stops at the first pause. For a long meeting recording, use continuous recognition (`start_continuous_recognition` with a `recognized` event handler) or batch transcription.

### Text to speech with a neural voice

```python
speech_config.speech_synthesis_voice_name = "en-IN-NeerjaNeural"
# Save to a file. Leave audio_config out to play on the default speaker.
file_out = speechsdk.audio.AudioOutputConfig(filename="answer.wav")
synthesizer = speechsdk.SpeechSynthesizer(speech_config=speech_config, audio_config=file_out)

result = synthesizer.speak_text_async("Your train will arrive on platform 4.").get()
if result.reason == speechsdk.ResultReason.SynthesizingAudioCompleted:
    print("Saved answer.wav")
```

### SSML for control

Plain text uses the voice's defaults. SSML lets you slow a number down, add a pause, or pick a style that the voice supports.

```python
ssml = """
<speak version="1.0" xmlns="http://www.w3.org/2001/10/synthesis"
       xmlns:mstts="https://www.w3.org/2001/mstts" xml:lang="en-US">
  <voice name="en-US-AriaNeural">
    <mstts:express-as style="customerservice">
      Your booking is confirmed.<break time="500ms"/>
      Your PNR is <prosody rate="-30%">4 5 2 1 9 8 7 6 3 0</prosody>.
    </mstts:express-as>
  </voice>
</speak>"""
synthesizer.speak_ssml_async(ssml).get()
```

Not every voice supports every style, so check the voice list in the Speech playground before you rely on one.

<Callout type="exam">
Look for the direction. Audio in, text out is **speech to text** (SpeechRecognizer). Text in, audio out is **text to speech** (SpeechSynthesizer). "Change the speaking rate, add pauses, or use a different speaking style" points to **SSML**. "Natural, human-like voice" means a **neural voice**. And for one short utterance, recognize_once is fine; long audio needs **continuous** or **batch** transcription.
</Callout>

<DeepDive title="Custom speech and custom voice">

Custom speech trains recognition on your own audio and text so it gets domain words right, like drug names or station names. Custom neural voice and personal voice create a voice that sounds like a specific person; those are **limited access** features with an application and consent requirements, because a cloned voice can be misused. That's responsible AI showing up as product policy.

</DeepDive>
