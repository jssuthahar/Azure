keyTerms:
  - term: Computer vision
    definition: The area of AI that lets software interpret images and video, such as describing a scene or reading text in a photo.
  - term: Image analysis
    definition: Extracting captions, tags, objects, people and text from an image, as Azure Vision in Foundry Tools does.
  - term: Object detection
    definition: Finding each object in an image and returning its name, a confidence score and a bounding box.
  - term: OCR (optical character recognition)
    definition: Reading printed or handwritten text from an image or scanned document. Azure Vision calls this feature Read.
  - term: Multimodal model
    definition: A generative model that accepts more than one kind of input, such as text plus images, in the same prompt.
  - term: Image-generation model
    definition: A generative model, such as gpt-image-1, that creates or edits images from a text prompt.
  - term: Content credentials
    definition: Provenance metadata (based on the C2PA standard) attached to generated images so anyone can check they were made by AI.

## Start with a question

<Story question="Can my phone really tell what's in a photo, and can it draw a new one for me?">

Point your phone's camera at a shop sign in Chennai and it can read the Tamil text and translate it. Upload a photo of a broken tap and an assistant can tell you which part is cracked. Ask for "a poster of a monsoon tea stall, watercolour style" and you'll get a picture that never existed before.

That's two jobs. Reading images is **computer vision**. Making new ones is **image generation**. AI-901 expects you to know both, and to tell them apart.

</Story>

### Image analysis: fixed, predictable outputs

**Azure Vision in Foundry Tools** (the service that used to be called Computer Vision) runs a trained model over an image and returns structured results:

| Feature | What you get back | Example |
| --- | --- | --- |
| Caption | One sentence describing the whole image | "A man riding a bicycle on a city street" |
| Dense captions | Captions for several regions of the image | "a red helmet", "a yellow taxi" |
| Tags | Keywords with confidence scores | bicycle 0.99, street 0.95 |
| Object detection | Each object's name, confidence and bounding box | taxi at x=420, y=180, w=210, h=140 |
| People | Where people are in the image | Three boxes around three people |
| Read (OCR) | Lines and words of printed or handwritten text | "Thank you, visit again" printed on a receipt |

Facial recognition exists too, but it's a **limited access** feature that Microsoft only turns on for approved use cases. That's responsible AI in action.

### Multimodal models: ask anything about a picture

A **multimodal model** accepts text and images in the same prompt. You attach a photo of a fridge shelf and ask "Which items are running low?", and the model reasons over the image and answers. It's flexible, but the answer is generated, so it can be wrong. Treat it like a smart colleague's opinion, not a measurement.

### Image generation: text in, picture out

**Image-generation models** such as **gpt-image-1** create new images from a prompt, and can edit an existing image (for example, replace the background). Foundry's **guardrails** check both the prompt and the result for harmful content. Images from Azure OpenAI models also carry **content credentials**, provenance metadata built on the C2PA standard, so anyone can check that the picture was generated by AI. That supports the transparency principle.

<TryIt labs="ai-vision" text="Send a photo to a multimodal model, ask a question about it, then generate a brand-new image from a prompt." />

<Callout type="exam">
Watch the verb in the question. **Describe, tag, detect or read** an image points to image analysis or a multimodal model. **Create, draw or design** an image points to an image-generation model. "Show that an image was made by AI" points to **content credentials**.
</Callout>

<DeepDive title="Picking between Azure Vision and a multimodal model">

Azure Vision gives the same answer for the same image every time and returns exact coordinates, which matters if you're drawing boxes on a screen or counting items at scale. A multimodal model costs more per image (you pay per token, and images add tokens) and its wording changes run to run, but it can follow instructions like "return only the damaged items as JSON". Many teams use both: OCR for exact text, then a model to reason over that text.

</DeepDive>
