## Start with a question

<Story question="If a helper sits next to you while you cook, do you want them to hand you the salt, answer a question, or cook the whole dish?">

It depends on the moment. Sometimes you only want the salt passed before you reach for it. Sometimes you want to ask "is this oil hot enough?". And some evenings you'd happily say "make dinner, and tell me before you turn the oven on".

GitHub Copilot works the same way. **Inline suggestions** pass you the next line before you ask. **Ask** mode answers your question. **Edit** mode changes the files you point at. **Agent** mode takes the whole task and asks before it runs anything in your terminal.

</Story>

## Explain it like I'm 10

<Eli10>

Copilot is a helper sitting in your code editor.

When you pause while typing, it whispers a guess in grey. Press Tab to keep it, Esc to ignore it.

You can also talk to it in a chat box.

In Ask, it just answers. In Edit, it changes the pages you hand it. In Agent, it does the whole job and checks with you before pressing any big buttons.

</Eli10>

## The technical explanation

### Inline suggestions (ghost text)

When you pause while typing, the Copilot extension sends the code around your cursor as context and shows the reply as grey **ghost text**. Nothing goes into your file until you accept it.

| Action | Windows / Linux | macOS |
| --- | --- | --- |
| Accept the whole suggestion | Tab | Tab |
| Dismiss it | Esc | Esc |
| Next / previous alternative | Alt+] / Alt+[ | Option+] / Option+[ |
| Accept the next word only | Ctrl+Right Arrow | Cmd+Right Arrow |
| Open the completions panel (several options) | Ctrl+Enter | Ctrl+Enter |

Say you type the start of a function in `src/discount.js`:

```js
export function applyDiscount(total, code) {
  // ghost text appears here:
  const pct = CODES[code] ?? 0;
  return Math.max(0, total - (total * pct) / 100);
}
```

Writing a clear function name and a short comment first gives Copilot much better context than an empty file.

**Next edit suggestions (NES)** go a step further. Rename a parameter on line 3, and Copilot predicts the matching edit on line 9 and offers it. You jump to it and press Tab.

To turn completions off for one language, set `github.copilot.enable` in your settings, for example `{ "*": true, "markdown": false }`. The Copilot icon in the status bar also lets you snooze suggestions.

### Inline chat (Ctrl+I)

Select some code, press **Ctrl+I** and type what you want: "make unknown codes return the total unchanged". Copilot shows the change as a diff in place. **Accept** keeps it, **Discard** throws it away. Use it for small, local changes where opening a full chat would be overkill.

### The Chat view and its three modes

Open the Chat view with **Ctrl+Alt+I**. A picker at the bottom switches the mode.

Here's the same request in each mode: "Add a FREE code that gives 100% off, with tests."

- **Ask** explains how you'd do it and shows code. You copy what you want.
- **Edit** changes `src/discount.js` and `tests/discount.test.js` if you added them, and waits for Keep or Undo.
- **Agent** searches the codebase, edits both files, asks to run `npm test`, reads the result and fixes a failure before reporting back.

### Outside VS Code

Visual Studio, JetBrains IDEs, Xcode, Eclipse and Vim/Neovim all have Copilot extensions with inline suggestions, and most have chat. Feature names and shortcuts differ a little, so check the docs for your editor. In the terminal, **Copilot CLI** (the `copilot` command) gives you an agent that reads your repo, edits files and runs commands with your permission. On github.com you can assign an issue to the **Copilot coding agent**, which opens a draft pull request.

<Callout type="exam">
Questions describe a need and ask for the surface. "Explain this code without changing it" is **Ask**. "Apply a change across files I choose and review each diff" is **Edit**. "Implement it, run the tests and fix what fails" is **Agent**. "Change just this selection right here" is **inline chat (Ctrl+I)**. Know the keys too: **Tab**, **Esc**, **Alt+]**, **Ctrl+Right Arrow** for one word, and `github.copilot.enable` to switch completions off for a language.
</Callout>

<DeepDive title="Why suggestions change when you open other tabs">

Inline suggestions don't only look at the current file. The extension also pulls snippets from **other open tabs** and neighbouring files to build the prompt, then trims it to fit the model's **context window**. That's why a test file open next to your code gives better suggestions, and why ten unrelated tabs can make them worse. Chat works differently: it uses the active file, your selection and whatever you add with `#file`, `#codebase` or a participant such as `@workspace`. Agent mode searches the workspace on its own. If a file is covered by a content exclusion, Copilot won't use it as context or suggest inside it in supported IDEs.

</DeepDive>
