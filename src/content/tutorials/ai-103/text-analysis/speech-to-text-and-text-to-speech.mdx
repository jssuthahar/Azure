## Start with a question

<Story question="What happens if the pharmacy agent hears 'met for men' instead of Metformin?">

Contoso Pharmacy wants a phone agent. A caller says, "I need a refill of Metformin 500." The speech model hears "met for men 500". The agent looks for a drug that doesn't exist, apologises, and the caller hangs up.

Nothing is wrong with the agent's brain. The mistake happened one step earlier, at the ears, and every later step inherited it. A voice agent is only as good as its **speech in** and **speech out**.

</Story>

## Explain it like I'm 10

<Eli10>

A voice agent is a phone call with a robot receptionist.

**Speech to text** is her ears and a notepad: she writes down what you say. **The model** is her brain: it decides what to answer. **Text to speech** is her mouth.

If the notepad says "met for men", her brain tries to answer the wrong question. A **phrase list** is a sticky note beside the notepad: "Words you'll hear: Metformin, Atorvastatin". **SSML** is a tip for her mouth: "pause here, say the time slowly".

</Eli10>

## The technical explanation

### The voice loop

1. **Speech to text** (Azure Speech): real-time recognition of the caller's audio.
2. **Model or agent**: reads the text and answers.
3. **Text to speech**: a **neural voice** such as `en-IN-NeerjaNeural` speaks the answer.

```python
import azure.cognitiveservices.speech as speechsdk

cfg = speechsdk.SpeechConfig(subscription=KEY, endpoint=ENDPOINT)
cfg.speech_synthesis_voice_name = "en-IN-NeerjaNeural"
recognizer = speechsdk.SpeechRecognizer(cfg, speechsdk.audio.AudioConfig(filename="question.wav"))
heard = recognizer.recognize_once().text
reply = ask_agent(heard)
speechsdk.SpeechSynthesizer(cfg).speak_text_async(reply).get()
```

### Domain words: phrase list or custom speech

| | Phrase list | Custom speech |
| --- | --- | --- |
| Best for | A handful of names and terms | Many terms, accents, noisy lines, industry vocabulary |
| Data needed | None | Related text and/or audio with human-labelled transcripts |
| Training | None | Train, test, deploy an endpoint |
| In code | `PhraseListGrammar.addPhrase("Metformin")` | `cfg.endpoint_id = "<custom endpoint ID>"` |

Start with the phrase list. Move to custom speech when the list stops helping.

### Shape the voice with SSML

Plain text uses the voice's defaults. **SSML** is XML that controls the delivery:

```xml
<speak version="1.0" xmlns="http://www.w3.org/2001/10/synthesis" xml:lang="en-IN">
  <voice name="en-IN-NeerjaNeural">
    Your Metformin is ready <break time="300ms"/>
    <prosody rate="-10%">after 5 PM.</prosody>
  </voice>
</speak>
```

Use `<break>` for pauses, `<prosody>` for rate and pitch, and the voice's style options where supported. SSML changes how the answer sounds. It never fixes what was heard.

### Voice Live for live agents

Stitching three calls together adds delay and makes interruptions awkward. **Voice Live** exposes a single real-time connection: audio goes in, a model (such as gpt-4.1-mini) or a **Foundry agent** answers, and audio comes back out. It includes **noise suppression**, **echo cancellation** and **end-of-utterance (turn) detection**. Choose it for phone agents, kiosks and anywhere a pause of a second feels wrong.

<Callout type="exam">
**Small number of words, no training** is a **phrase list**. **Industry vocabulary, accents or noise** is **custom speech**, used through its **endpoint ID**. **Pauses, rate or pitch** are **SSML**. **One low-latency connection for speech in and out with an agent** is **Voice Live**.
</Callout>

<DeepDive title="Why recognition errors travel so far">

An agent has no ears of its own. It only sees the transcript. If the transcript is wrong, the agent can be completely confident and completely wrong. That's why teams measure **word error rate** on their own recordings, test the hard vocabulary first, and keep a confirmation step ("Did you say Metformin 500?") for actions that matter, like refills or payments.

</DeepDive>
