## Start with a question

<Story question="An insurance clerk has 2,000 claim photos and a spreadsheet with a column called 'Damage type'. Can the photos fill that column on their own?">

A chat model can describe each photo, but one reply says "a dent near the door" and the next says "the vehicle shows damage". A spreadsheet needs "dent" every time.

**Content Understanding** fixes that. You define the fields once, such as DamageType with four allowed values, and every photo comes back as the same record.

</Story>

## Explain it like I'm 10

<Eli10>

Picture a form with boxes: "What's damaged?" and "Write one sentence about it."

A helper looks at each photo and fills in the same boxes, every time. For a long video, the helper first cuts it into scenes, then fills in a form for each scene.

The form is the **analyzer**. The cutting is **segmentation**.

</Eli10>

## The technical explanation

Content Understanding is a Foundry Tool. You call an **analyzer** with a file and get **fields** back, with confidence scores. It uses model deployments on your resource, so the resource needs default deployments such as a chat model before analyzers run. The API version used in this lesson is 2025-11-01 (checked 25 November 2026).

### Prebuilt analyzers

| Analyzer | Returns |
| --- | --- |
| `prebuilt-imageSearch` | A description of the image, for search indexes |
| `prebuilt-videoSearch` | The video split into segments with descriptions, key frames and transcript |

### Custom analyzers: single-task

A custom analyzer starts from a base (`prebuilt-image` or `prebuilt-video`) and adds a **field schema**.

```python
from azure.ai.contentunderstanding import ContentUnderstandingClient
from azure.identity import DefaultAzureCredential

client = ContentUnderstandingClient(endpoint=endpoint, credential=DefaultAzureCredential())
# A field schema, in the analyzer definition
fields = {
  "DamageType": {"type": "string", "method": "classify",
                 "enum": ["dent", "scratch", "broken glass", "none"]},
  "Notes":      {"type": "string", "method": "generate",
                 "description": "One sentence on what is damaged and where."},
}
poller = client.begin_analyze(analyzer_id="damage-photo", inputs=[AnalyzeInput(url=photo_url)])
print(poller.result().contents[0].fields)
```

| Method | What it does | Works for |
| --- | --- | --- |
| `extract` | Reads a value written in the content | Documents only |
| `classify` | Picks one value from your list | Images, video, audio, documents |
| `generate` | Writes a value from understanding the content | Images, video, audio, documents |

### Video: segmentation

A video analyzer can treat the file as **one segment** or split it. With **segmentation on** you describe the scenes, for example "one segment per training topic". You get the whole video plus each segment with its own **fields**, **key frames** and **WEBVTT transcript**. Your search app can then jump straight to 03:10 instead of replaying 12 minutes.

### Pro mode

**Standard** analyzers apply one analysis task to the input. **Pro mode** adds **multi-step reasoning** that can use **several inputs** and **reference data**, which suits checks such as validating a submission against a policy. Support depends on the content type and changes over time, so read the current Learn page before you rely on it.

### Finding objects and regions

For "where is it?" you have two options. A **generate** field can describe objects and, for video, when they appear. Or ask a multimodal model for labels and boxes. Either way, confidence is limited, so show the result to a reviewer when the decision matters.

<Callout type="exam">
"The same fields for every file" = **custom analyzer**. "extract on a photo analyzer fails" = use **classify or generate**. "Find the part of a video about forklifts" = **segmentation**. "Compare against reference data" = **pro mode**.
</Callout>

<DeepDive title="Why does a video with segmentation off still return something?">

Without segmentation the analyzer treats the whole file as one content item. You still get the fields you defined, plus a transcript, for the full video. That's the right choice for whole-video questions, such as "does this clip show a brand logo anywhere?", where you don't need chapters.

</DeepDive>
